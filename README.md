# Avataria Helper

Мод-меню для Аватарии и Тропикании: окно помощника поверх игры, которое
берёт на себя рутину - танцы, промокоды, энергию, ежедневный подарок - и
ведёт статистику по дням и за всё время.

## Установка

Скачай `AvatariaHelperSetup.exe` со страницы
[Releases](https://github.com/Deatser/Avataria-Helper/releases/latest) и
запусти. Права администратора не нужны: приложение ставится в папку
пользователя, настройки и статистика живут в `%APPDATA%\Avataria Helper` и
переустановку переживают.

Windows покажет синее окно «Защитник Windows предотвратил запуск» -
установщик не подписан сертификатом. Нажми «Подробнее», затем «Выполнить в
любом случае».

**Нужен лаунчер Tortuga Game Club**: помощник работает с игрой, запущенной
через него.

## Что умеет

- **Ava Dancers** - автоматическая игра в танцы
- **Тропикания** - своё окно со своей статистикой
- **Промокоды** - сбор и активация
- **Энергия** - закуп в кафе
- **Статистика** - за день и за всё время
- ежедневный подарок собирается сам

Садовник, Уборщик, Хоккей, Сноуборд и Кулинар помечены «В разработке» и
пока не открываются.

## Запуск из исходников

Нужен Python 3.13 и Windows.

```
py -m pip install -r requirements.txt
py main.py
```

## Сборка установщика

Нужен [Inno Setup 6](https://jrsoftware.org/isdl.php).

```
py -m PyInstaller --noconfirm AvatariaHelper.spec
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

Готовый установщик появится в `Output\AvatariaHelperSetup.exe`.
